# Esor's Frontend Studio

Build a professional, modern portfolio website for a frontend web developer named Esor Ezekiel, specializing in HTML, CSS, JavaScript, and Tailwind CSS. The site should position him as a skilled, detail-oriented frontend developer ready for freelance/client work and full-time roles.

Structure:

Hero section — Full name, title ("Frontend Web Developer"), a one-line value proposition (e.g. "I build fast, responsive, pixel-perfect web experiences"), profile photo, and a CTA button ("View My Work" / "Hire Me").

About — Short bio: background, what drives him, tech stack (HTML5, CSS3, JavaScript, Tailwind CSS, React), and years/type of experience.

Skills — Visual grid or icon row of core skills: HTML, CSS, JavaScript, Tailwind CSS, React, Responsive Design, UI/UX principles, Git/GitHub.

Projects showcase (the centerpiece) — Cards for each project with: screenshot/preview image, project name, one-line description, tech stack used, and two links ("Live Demo" and "View Code"). Feature these projects:

Solar-Max — Solar energy company landing page (React, Tailwind, Vite)

SpiceDesk — Premium restaurant mobile app UI (React, Tailwind, dark theme)

kings-view — React/Vite frontend project

OptimaCare — Healthcare-themed frontend build

EP-CREATIVE — Creative agency-style site (HTML/CSS/JS)

nextnews — News/media frontend

Testimonials (optional, add placeholder if none yet) — Client or peer feedback.

Contact — Contact form or mailto link, LinkedIn (in/esor-ezekiel-173402212), GitHub, and any other socials.

Design direction: Clean, modern, minimal — generous white space, one accent color, smooth scroll and subtle hover/entrance animations, fully responsive (mobile-first), fast-loading, accessible (semantic HTML, good contrast, alt text on images). Typography should feel professional, not generic template-default.

Tone: Confident, competent, not overdone — this is a working developer's portfolio, not a personal blog. the image uploaded is my picture
